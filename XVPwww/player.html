关于 XVP

XVP
短视频风格播放器
v3.0

功能简介

• 短视频风格全屏播放，上下滑动切换视频

• 支持 Emby / Jellyfin / 飞牛影视媒体库

• 双击屏幕点赞收藏，点击视频暂停/播放

• 长按画面 2 倍速播放，左右拖动快进快退

• 左上角菜单：视图模式 / 播放模式 / 媒体库 / 个人中心

• 网格视图浏览全部视频，一键收藏筛选

• 播放列表管理，自动连播与随机播放

• 短剧模式：按剧集顺序自动连播

版本升级记录

v3.0
XVP 介绍页改版
  • 首页改为 App 介绍页（5nav 风格），播放器移至 player.html
  • 点击应用图标 5 次进入播放器，防误入
  • 介绍页含功能特色 / 播放性能 / 快捷键指南 / 截图轮播
  • 支持浅色/深色主题切换，适配手机与桌面
v2.0
XVP 全面改版
  • 项目更名：EmbyX → XVP
  • 底部导航移除，功能并入左上角菜单
  • 收藏按钮移至标题栏右侧，点击即收藏
  • 新增“关于 XVP”页面，展示功能与版本记录
  • 移除上游 GitHub 更新检查，本地定制版专用
v1.x
